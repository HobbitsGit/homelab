MAM Setup

Dynamic Seedbox Registration

MAM requires your VPN IP to be registered as an authorized seedbox IP. Since the VPN IP can change, this is handled dynamically.

1

Create a seedbox session on MAM

Go to Preferences → Security → Create Session. Enter your current VPN IP, enable ASN locked and Allow session to set Dynamic Seedbox. Copy the long session string.

2

Add additional ASNs if needed

ProtonVPN uses multiple data center providers (WorldStream ASN 49981, NForce ASN 43350). Add each via Manage Session → Add ASN via IP address.

3

Register the VPN IP

docker exec qbittorrent curl -c /scripts/mam.cookies \
  -b 'mam_id=YOUR_SESSION_STRING' \
  https://t.myanonamouse.net/json/dynamicSeedbox.php

Should return "Success":true

Auto-Refresh (User Scripts)

The MAM cookie is stored at /scripts/mam.cookies inside the qBittorrent container. A User Script refreshes it every 30 minutes:

docker exec qbittorrent curl -c /scripts/mam.cookies -b /scripts/mam.cookies \
  https://t.myanonamouse.net/json/dynamicSeedbox.php

Schedule: */30 * * * * in User Scripts plugin.

Tracker Errors

ErrorFix
Port 6881 is blacklistedChange qBit listening port to 38077 (or current forwarded port)
Unrecognized host/PassKeyRe-run the dynamic seedbox curl command to update IP
Invalid session - ASN mismatchAdd the new ASN via Manage Session on MAM using the current VPN IP
Invalid session - IP mismatchSession cookie was created from wrong IP — create new session from VPN IP

Port Forwarding (ProtonVPN)

Gluetun handles port forwarding automatically via ProtonVPN. The forwarded port is written to /tmp/gluetun/forwarded_port inside the Gluetun container.

A User Script syncs the port to qBittorrent every 30 minutes:

bash /mnt/user/appdata/qbittorrent/scripts/sync-port.sh

Schedule: */30 * * * *

Hardlink Script

✓
Hardlinks create a second pointer to the same data on disk. Zero extra storage used. Deleting from /torrents/ does not affect the copy in /media/.

Script Location

Script is stored on the Unraid host and mounted into the qBittorrent container:

LocationPath
Host/mnt/user/appdata/qbittorrent/scripts/on-complete.sh
Container/scripts/on-complete.sh

Script

#!/bin/bash

CATEGORY="$1"
FILE_PATH="$2"
LOG="/scripts/on-complete.log"

case "$CATEGORY" in
  audiobooks)
    DEST="/data/media/audiobooks"
    ;;
  ebooks)
    DEST="/data/media/ebooks"
    ;;
  comics)
    DEST="/data/media/comics"
    ;;
  manga)
    DEST="/data/media/manga"
    ;;
  *)
    echo "$(date) - Skipping category: $CATEGORY" >> "$LOG"
    exit 0
    ;;
esac

cp -rl "$FILE_PATH" "$DEST/"
echo "$(date) - Hardlinked $FILE_PATH to $DEST" >> "$LOG"

qBittorrent Configuration

In qBittorrent → Settings → Downloads → Run external program on torrent completion:

/scripts/on-complete.sh "%L" "%F"

%L = category label  ·  %F = content path

Testing

# Create a test file
touch /mnt/user/data/torrents/audiobooks/test.epub

# Run the script manually
docker exec qbittorrent /scripts/on-complete.sh audiobooks "/data/torrents/audiobooks/test.epub"

# Verify hardlink appeared
ls /mnt/user/data/media/audiobooks/

# Check the log
cat /mnt/user/appdata/qbittorrent/scripts/on-complete.log

# Clean up test files
rm /mnt/user/data/torrents/audiobooks/test.epub
rm /mnt/user/data/media/audiobooks/test.epub

Fixing Metadata

⚠️
Always fix metadata before running the organizer script. The organizer reads directly from ABS — bad metadata creates bad folder names.

Fields That Matter for Organization

FieldUsed forExample
AuthorTop-level folderBrandon Sanderson
SeriesSeries folderThe Mistborn Saga
Series SequenceNumber prefix on book folder#1 → 01 -
TitleBook folder nameThe Final Empire

How to Fix Metadata

1

Open the book in Audiobookshelf

Click the book → click the pencil/edit icon

2

Go to the Match tab

Select Audible.com as provider, search by title and author. If you have the ASIN from Audible, use that directly for a precise match.

3

Verify the result

Check that Author is correct (not the narrator), Series name is consistent with other books in the series, and sequence number is set.

4

Save & Close

Common Metadata Problems

ProblemFix
Narrator listed as authorManually correct Author field — common with Jim Dale Harry Potter editions
Series field emptyAdd series name and sequence manually
Inconsistent series namesMake sure all books in a series use identical series name text
Multi-book torrent not matchingSplit into per-book subfolders first, rescan, then match individually
Author shows translatorSet Author to original author (e.g. Homer, not Emily Wilson - translator)

Splitting Multi-Book Torrents

When a single torrent contains an entire series (e.g. ASOIAF 1–5), ABS can't match it to a single book. Split it into per-book subfolders first:

# Example: A Song of Ice and Fire
BASE="/mnt/user/data/media/audiobooks/george r. r. martin a song of ice and fire 1-5 m4b"

mkdir -p "$BASE/A Game of Thrones"
mkdir -p "$BASE/A Clash of Kings"
mkdir -p "$BASE/A Storm of Swords"
mkdir -p "$BASE/A Feast for Crows"
mkdir -p "$BASE/A Dance with Dragons"

mv "$BASE/"*"game of thrones"* "$BASE/A Game of Thrones/"
mv "$BASE/"*"clash of kings"* "$BASE/A Clash of Kings/"
mv "$BASE/"*"storm of swords"* "$BASE/A Storm of Swords/"
mv "$BASE/"*"feast for crows"* "$BASE/A Feast for Crows/"
mv "$BASE/"*"dance with dragons"* "$BASE/A Dance with Dragons/"

Then trigger a library scan in ABS — it will see 5 separate books.

Library Default Provider

Set the library default to Audible.com so every new match defaults to the right provider:

Settings → Libraries → Audiobooks → Metadata Provider → Audible.com

Matching by ASIN

For precise matches (especially when multiple editions exist), use the Audible ASIN directly in the Match tab search field. The ASIN is in the Audible URL: audible.com/pd/title/B01234567 — the B01234567 part.

Martin/ │ └── A Song of Ice and Fire/ │ ├── 01 - A Game of Thrones/ │ │ ├── part 1.m4b │ │ ├── part 2.m4b │ │ └── part 3.m4b │ └── 02 - A Clash of Kings/ └── Susanna Clarke/ └── Piranesi/ <-- no series, so Author/Title only └── Piranesi by Susanna Clarke.m4b

Structure Rules

ConditionStructure
Book has series + sequenceAuthor / Series / ## - Title /
Book has series, no sequenceAuthor / Series / Title /
Standalone book (no series)Author / Title /

Notes

  • Series numbers are zero-padded (1 → 01, 10 → 10) for correct alphabetical sort
  • Multi-part books (part 1, part 2) go inside the same book folder
  • The organizer strips #N and extra series info from series names (e.g. Harry Potter #1, Wizarding World Collection #1 → Harry Potter)
  • Audiobookshelf does not require clean folder structure — this is purely for browsing via file manager

Organizer Script

Script Location

LocationPath
Host/mnt/user/appdata/audiobookshelf/scripts/abs-organize.js
Container/scripts/abs-organize.js

How to Run

1

Dry run first (default)

The script always runs in dry run mode by default — it logs what it would do without moving anything.

docker exec audiobookshelf node /scripts/abs-organize.js
2

Review the log

cat /mnt/user/data/media/audiobooks/organize.log

Confirm the moves look correct before proceeding.

3

Set DRY_RUN = false and run for real

sed -i 's/DRY_RUN = true/DRY_RUN = false/' \
  /mnt/user/appdata/audiobookshelf/scripts/abs-organize.js

docker exec audiobookshelf node /scripts/abs-organize.js
4

Reset DRY_RUN back to true

sed -i 's/DRY_RUN = false/DRY_RUN = true/' \
  /mnt/user/appdata/audiobookshelf/scripts/abs-organize.js

What the Script Does

  • Calls the ABS API to get all books in the Audiobooks library
  • For each book, reads title, author, series name, and sequence number from ABS metadata
  • Strips series number from series folder name (Mistborn Saga #1 → Mistborn Saga)
  • Prepends sequence to book folder (#1 → 01 - Title)
  • Moves directories by moving their contents to avoid double-nesting
  • Skips books already in the correct location
  • Logs every action to /audiobooks/organize.log
⚠️
After running the organizer, trigger a library rescan in Audiobookshelf so it picks up the new file paths. Settings → Libraries → Audiobooks → Scan Library.
🧹

Cleanup

Remove Empty Folders

After the organizer runs, leftover empty folders remain (e.g. A Song of Ice and Fire #1/). Remove them all in one command:

find /mnt/user/data/media/audiobooks -type d -empty -delete
ℹ️
This is safe to run at any time — it only deletes directories that are completely empty.

Removing Completed Torrents

Once a torrent has hit its seeding ratio (2.0) and stopped, it's safe to remove:

1

In qBittorrent, filter by Stopped status

2

Right-click → Remove (not "Remove and delete files")

3

The file in /data/torrents/audiobooks/ is deleted. The hardlinked copy in /data/media/audiobooks/ is unaffected.
